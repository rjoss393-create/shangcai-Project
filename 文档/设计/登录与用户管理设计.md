# 登录与用户管理设计（2026-09-17）

> 范围：**仅后端**（控制层 `/api/auth` + 数据访问层 `service/user_store.py`）。
> 前端页面/交互不在本设计内；本文档同时作为对前端的接口契约。
> 无新增第三方依赖（密码哈希、令牌均用 Python 标准库）。

## 一、目标与功能

| 角色 | 能做什么 |
|---|---|
| 游客 | 注册（`/register`）、登录（`/login`） |
| 普通用户 user | 退出、查看本人信息、修改本人密码 |
| 管理员 admin | 上述全部 + 用户列表、改角色、启停账号、重置他人密码、删除用户 |

用户信息存 JSON 文件（`data/users.json`），不引入数据库。

## 二、数据模型（data/users.json）

```json
{
  "users": [
    {
      "username": "alice",
      "password_hash": "pbkdf2_sha256$120000$1f3c...$9a7b...",
      "role": "admin",
      "status": "active",
      "created_at": "2026-09-17T06:07:51+00:00"
    }
  ]
}
```

| 字段 | 说明 |
|---|---|
| `username` | 3~20 位字母/数字/下划线，唯一（限制为 ASCII 是为了避免 URL、日志、编码问题） |
| `password_hash` | 见下节；**任何接口响应中都不出现此字段** |
| `role` | `admin` 管理员 / `user` 普通用户 |
| `status` | `active` 正常 / `disabled` 已停用（停用后不能登录，已签发令牌立即失效） |
| `created_at` | UTC ISO 时间，用于用户列表排序 |

- 该文件是**运行期状态文件**，已加入 `.gitignore`（不入库）；
- 文件不存在时以空用户表启动，首次写入时创建；
- 写入方式：先写 `users.json.tmp` 再 `os.replace` 原子替换，避免写一半损坏。

## 三、安全策略

**密码**
- 算法 PBKDF2-HMAC-SHA256，120000 次迭代，每个用户 16 字节随机盐；
- 存储格式 `pbkdf2_sha256$迭代次数$盐(hex)$哈希(hex)`；
- 校验用 `hmac.compare_digest`（恒定时间比较，防时序侧信道）；
- 明文密码不落盘、不入日志、不出现在响应里；不用 MD5/SHA1。

**登录令牌（Token）**
- `secrets.token_urlsafe(32)` 随机串，**本身不含用户信息**，服务端 `TokenManager` 记录 `token -> 用户名 + 过期时间`；
- 有效期 24 小时（`auth.TOKEN_TTL_SECONDS`），过期即失效；
- 存储为**进程内内存**（与 `context_manager` 会话同一思路，重启后需重新登录，接口已预留 Redis/JWT 替换空间）；
- 令牌撤销时机：主动退出、修改密码、被重置密码、被停用、被删除。

**其他**
- 登录失败统一返回"用户名或密码错误"，不区分账号是否存在（避免账号枚举）；
- 用户名重复、密码强度不足等校验在 `UserStore` 内统一做（service 层单一事实源）。

## 四、权限模型

- 权限完全由 `role` 决定：`admin` 可访问全部管理接口，`user` 访问即 403；
- **系统第一个注册的用户自动成为 admin**（初始化方式，避免预置一个默认密码的账号）；
- 自我保护：管理员不能降级/停用自己的账号（自己的 role/status），也不能删除自己 → 400，防止把系统锁死没管理员。

## 五、接口清单（前缀 `/api/auth`）

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| POST | `/register` | 公开 | 注册并直接返回令牌（首个用户自动为 admin） |
| POST | `/login` | 公开 | 账号密码登录 |
| POST | `/logout` | 登录 | 退出登录（撤销当前令牌） |
| GET | `/me` | 登录 | 当前用户信息（可校验令牌是否仍有效） |
| POST | `/password` | 登录 | 修改本人密码（需原密码；改完令牌全部作废需重登） |
| GET | `/users` | admin | 用户列表（不含密码哈希） |
| PATCH | `/users/{username}` | admin | 改角色 / 启停 |
| POST | `/users/{username}/password` | admin | 重置他人密码 |
| DELETE | `/users/{username}` | admin | 删除用户 |

登录后的接口统一带请求头：`Authorization: Bearer <token>`。

### 请求 / 响应示例

注册、登录（响应结构相同）：

```jsonc
// POST /api/auth/register  {"username": "alice", "password": "pass123"}
// 200
{
  "token": "wWZ9c_pNDqLx...",
  "user": {"username": "alice", "role": "admin", "status": "active",
           "created_at": "2026-09-17T06:07:51+00:00"},
  "message": "注册成功（首位用户已自动成为管理员）"
}
```

```jsonc
// GET /api/auth/me  -> 200
{"username": "alice", "role": "admin", "status": "active", "created_at": "..."}

// POST /api/auth/password  {"old_password": "pass123", "new_password": "newpass1"}
// 200
{"message": "密码已修改，请使用新密码重新登录"}
```

```jsonc
// GET /api/auth/users -> 200
{"total": 2, "users": [{"username": "alice", "role": "admin", "status": "active", "created_at": "..."},
                       {"username": "bob", "role": "user", "status": "active", "created_at": "..."}]}

// PATCH /api/auth/users/bob  {"role": "admin"}  或  {"status": "disabled"}
// 200 -> 该用户的最新信息
{"username": "bob", "role": "admin", "status": "active", "created_at": "..."}

// DELETE /api/auth/users/bob -> 200
{"message": "已删除用户 bob"}
```

### 错误约定（FastAPI HTTPException，错误信息在 `detail`）

| 状态码 | 场景 |
|---|---|
| 400 | 参数/业务错误：用户名不合法、密码过短、用户名已注册、原密码错误、自我降级/删除 |
| 401 | 未带令牌 / 令牌无效或过期 / 账号被停用 / 用户名或密码错误 |
| 403 | 已登录但不是管理员（调用管理接口） |
| 404 | 目标用户不存在 |
| 422 | 请求体结构不合法（缺字段、类型错，FastAPI 默认校验） |

## 六、文件与装配

| 文件 | 职责 |
|---|---|
| `backend/service/user_store.py` | JSON 读写 + 密码哈希 + 用户增删改查（数据访问层，不依赖 controller） |
| `backend/controller/auth.py` | `TokenManager`（令牌）+ `create_auth_router(user_store)` 路由工厂 |
| `backend/tests/test_user_store.py` | 存储/哈希/持久化测试 11 例 |
| `backend/tests/test_auth_router.py` | 接口/权限/令牌测试 16 例 |

```python
# main.py / mock_main.py 中的装配
from service.user_store import UserStore
from controller.auth import create_auth_router

user_store = UserStore(path=os.path.join(ROOT, "data", "users.json"))
app.include_router(create_auth_router(user_store))
```

`mock_main.py`（前后端联调服务）已挂载同一套接口，且与正式入口共用同一个 `data/users.json`，两边注册的账号通用。

跑测试：`cd backend && python -m pytest -q`（全量 96 例通过）。
