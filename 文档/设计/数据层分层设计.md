# 数据层分层设计（2026-09-14）

> 本文档定义知识图谱数据层的三层分层结构，供数据层生成、控制层接入、前端渲染三方对齐。
> 生成脚本：`scripts/generate_layered_data.py`；产物：`data/layered/{graph_id}_layered.json`。

## 一、三层定义（对齐前端缩放层级）

| 层 | 前端 zoom | 节点类型 | 含义 |
|---|---|---|---|
| macro 宏观层 | 总览（scale ≤ 0.4） | `chapter` | 只显示这本书的章节节点 |
| meso 中观层 | 脉络（0.4 < scale ≤ 0.8） | `section` | 每个章节的内容节点（节） |
| micro 微观层 | 聚焦（scale > 0.8） | `concept` / `formula` | 章节里的具体内容 |

经济综合（econ，四书融合图谱）同样按此规则分层。

## 二、节点 schema（在原始字段基础上新增）

```json
{
  "id": "concept_0001",
  "label": "资本结构",
  "type": "concept",
  "page": 365,
  "layer": "micro",
  "parents": ["chapter_0001", "section_0002"]
}
```

- `layer`：macro / meso / micro，**前端按此字段过滤显示，不再依赖 category**
- `parents`：所属层级路径（章 id → 节 id），供下钻导航与分组
  - chapter 节点：`[]`
  - section 节点：`[章id]`
  - concept/formula 节点：`[章id, 节id]`；**章直挂概念**（原始数据无中间节）只标 `[章id]`

## 三、边 schema（原始边保留 + 派生边）

```json
{ "source": "chapter_0001", "target": "section_0002", "relation": "包含章节", "layer": "hier" },
{ "source": "chapter_0001", "target": "chapter_0005", "relation": "相关", "layer": "macro" }
```

| 边 layer | 含义 | 用法 |
|---|---|---|
| `hier` | 原始包含关系（包含章节/包含概念/包含公式） | 下钻导航（点击章→进入其节），不作为该层连线显示 |
| `macro` | 章-章派生"相关"边 | 宏观层连线 |
| `meso` | 节-节派生"相关"边 | 中观层连线 |
| `micro` | 概念-概念派生"相关"边 | 微观层连线 |

## 四、清洗与派生规则

1. **章直挂概念**：保留直挂，`parents` 只标章（不虚构节节点）。
2. **孤节点**（原始数据无任何边）：按 `page` 页码归入所在章/节（章、节按页码排序构成区间，落在区间内即归属）；页码缺失的丢弃（仅从分层文件剔除，原始文件不受影响）。
3. **派生相关边**（解决原始数据只有纵向包含边、层内无连线的问题）：
   - 宏观：两章共享概念数 ≥ 3 → "相关"边
   - 中观：两节共享概念数 ≥ 2 → "相关"边
   - 微观：同一父级（节或章）内概念按页码排序，每概念连后 ≤ 3 个近邻
   - 每节点派生边上限 8 条（按共享数/页序取前 8，防节点过密）
4. 阈值均为脚本常量（`CHAPTER_SHARE_MIN` / `SECTION_SHARE_MIN` / `MICRO_NEIGHBOR` / `DERIVED_EDGE_CAP`），调整后重跑脚本即可。

## 六、消费方式（前端 / 控制层）

- **前端**：一次 `/api/graph/load` 拿到全图后，按 `node.layer` 与当前 zoom 层过滤渲染；每层只画该层 `layer` 的边；`hier` 边仅用于点击下钻（如点击某章 → 定位到它的节群）。
- **控制层**：`data_service.GRAPH_FILES` 改为指向 `layered/*_layered.json`（节点/边字段与《字段.md》兼容，多余字段经 extra 兜底透传）；graph_id 编码含 invest（5 个图谱）。
- **再生成**：数据层更新原始图谱后，运行
  `python scripts/generate_layered_data.py`（可选 `--src` / `--out` 参数）。

## 七、与《字段.md》的关系

分层文件是原始知识图谱的**派生视图**：必填字段（id/label/type + source/target/relation）不变，
新增 layer/parents/边 layer 为扩展字段；Agent 层拿到的 GraphData 不受影响（extra 兜底）。
