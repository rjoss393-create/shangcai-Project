## 0. 一句话概括

本次更新只做一件事：**课程板块的书架接入了教材电子版，点封面 → 详情里能直接读原文**。

1. **书架重做**：35 本 → **32 本**，删掉了 5 本没有电子版的教材（含《投资学》《公司金融》《并购与重组》三本主课教材）；**剩下 32 本每一本都能读**。
2. **新增「📖 阅读原文」**：在书籍详情弹窗里，PDF 走浏览器内嵌阅读器、EPUB 走 epub.js 分页渲染，**不用下载、不外跳**。
3. **封面全部换成真封面**：从各自的电子版里抽出来（28 张真封面 + 4 张占位卡片），不再用之前那批对不上的占位图。

> ⚠️ **本次包体约 495.7 MB（≈473 MiB），不是上次的 5 MB**——因为把 32 本教材原文一起打进来了。
> 这是刻意的：不带教材，详情里的「📖 阅读原文」在服务器上会全部 404。
>
> **体积口径务必分清**（下面的数字别混）：
>
> | 看什么 | 数字 | `du -h` / 资源管理器"大小"显示 |
> |---|---|---|
> | **压缩包** `部署更新包_2026-09-23.zip` | 约 495.7 MB（`ls -l` 看到约 495,734,000 字节） | **约 473M** |
> | **解压落盘** `data/media/textbooks/`（32 个文件） | **518,188,679 字节** = 518.2 MB = **494.2 MiB** | **495M** ← 第 3 节核对用这个 |
> | 其余新增（28 张封面 + 前端 4 个资源 + 清单） | 约 2.4 MB | 可忽略 |
>
> 单位说明：「MB」= 10⁶ 字节，「MiB / `du` 显示的 M」= 2²⁰ 字节；本项目脚本里的 `totalMB` 用的是 **MiB**。
> 一句话：**压缩包 473M，解开后教材目录 495M**。两者差 22M 是 zip 压缩的效果，不是文件缺失。

**不需要 `pip install`**：`requirements.txt` 与上一版逐字节相同 —— 本次没有引入任何新的运行时 Python 依赖。
（`scripts/import_textbooks.py` 用到的 PyMuPDF/Pillow 只在**我们本机**生成数据时用，服务器上不跑。）

- 本次**不包含**、也**不需要重传** `videos/`、`papers/`、`videos.json`、`books/01–35.png`、`galaxy_v12.json`（均与上一版逐字节相同）。
- 若服务器上 `data/media/` **整个目录都不存在**（表现：首页视频无法播放、论文 PDF 404、所有封面空白），
  需要把媒体数据补齐，目录结构为：

  ```
  data/media/
    videos/           ← 80 个 mp4 + 80 张封面（约 4.8 GB）
    papers/           ← 13 个 PDF（约 17 MB）
    books/            ← 旧的 01–35.png（35 张，约 5.5 MiB，本次已不再被引用） + 本次新增的 tb-*.jpg（28 张，约 1.63 MiB）
    textbooks/        ← 【本次新增】32 个 PDF/EPUB（518,188,679 字节 = 494.2 MiB，du 显示 495M）
    videos.json       ← 视频清单（约 28 KB）
    courses.json      ← 课程星系数据（约 21 KB）
    textbooks.json    ← 【本次新增】教材清单（约 22 KB）
  ```

  补齐方式见项目内《测试环境说明.md》与 `scripts/import_videos.py`。
- 这些路径由后端 `backend/controller/media.py` 按**前端原有相对路径**对外提供
  （`/assets/videos/01.mp4`、`/assets/papers/jf-01.pdf`、`/assets/books/01.png`、`/assets/textbooks/x.pdf`、`/data/textbooks.json`），
  前端代码里写的就是这些地址，所以只要文件放对位置，**前端不用改任何一行**。

## 7. 回退方式

覆盖前若按第 3 节备份了 `前端/SUFE-Knowledge-Galaxy/`、`backend/controller/media.py`、`data/media/books/`，
回退时还原这三处 + 重启后端即可。**本次没有改数据库结构，也没有引入需要迁移的持久化格式。**

新增的 `data/media/textbooks/` 与 `data/media/textbooks.json` 不回退也**完全无害** ——
上一版的 `main.js` 不认识 `textbookId`，只会把它们当普通文件忽略。

**数据文件说明（不会丢）**：

- 用户账号在 `data/users.json`，个人笔记/收藏在 `data/profiles.json`，**重启后端不会丢**。
- 重启后会清空的只有**进程内的登录令牌与会话**（设计如此，用户需重新登录）。
- `data/layered/` 里的 7 个图谱（ma / corp_fin / intl_inv / invest / econ / v6 / v12）**本次一字未动**。
