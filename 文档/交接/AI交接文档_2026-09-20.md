## 2. 架构与必须遵守的契约

### 2.1 运行方式（单端口）

```bash
cd E:/上财项目(控制层)
python -m uvicorn main:app --host 127.0.0.1 --port 8000
# 或双击根目录 启动后端.bat（等价）
```

页面地址：`http://localhost:8000/index.html`（或 `/`）。**页面 / 数据 / 接口同一个端口**，不再需要 Node / proxy-server（已退役）。

- ✅ `main.py` 装配：`DataService`（数据层）+ `QaAgentImpl`（Agent 层）+ `create_router`（控制层）+ `UserStore` + `create_auth_router` + `ProfileStore` + `create_profile_router` + `create_media_router` + `mount_site`。
- ⚠️ **`mount_site(app, 前端目录)` 必须放在所有 API 路由注册之后**（它挂 `"/"`，先注册的路由优先匹配）。
- ✅ 启动事件后台按顺序预热 5 个图谱；日志出现 5 行 `[preload] xxx 预热完成` 才算就绪。
- ✅ 健康检查 `/health` → `{"status":"ok","agent":true}`；**`agent` 为 `false` 表示 API Key 或向量模型缓存没配好**（页面能开，问答会降级）。

### 2.2 控制层统一响应契约（改字段会连累前端）

`{code, message, session_id, data, answer, actions, degraded, notice}`——`answer` 是智能问答结果，前端按 `actions` 顺序播动画。**不要随意改 `actions` 结构**；细节见 `文档/协议/controller.txt`、`文档/协议/Service与Agent层接口协议.md`。

### 2.3 Agent 层契约（2026-09-11 起）

- `QaAgent.preload(graph_id, graph)`：页面打开时后台预热，不阻塞、不计熔断；
- `QaAgent.answer(graph_data, question)` → `AnswerResult`（`prediction_llm` / `prediction_html` / `related_nodes` / `retrieval_count` / `used_count`）；
- 控制层每次传**全图数据**（`graph_data` 内含 `graph_id`），并按 `related_nodes` 的 ID 调 Service 取子图做定位高亮。

### 2.4 graph_id 编码表（`backend/controller/graph_ids.py`，新增只加行、不改旧值）

`ma` 并购与重组 / `corp_fin` 公司金融 / `intl_inv` 国际投资学 / `invest` 投资学 / `econ` 经济综合（四书融合）。

### 2.5 容错参数与设计取舍

- 问答超时 **20s**（`dispatcher.QA_TIMEOUT_SECONDS`，Agent 缓存命中平均 2.7s）；熔断 3 次失败 / 冷却 10s；降级走 `Service.search_keywords` 关键词兜底。
- 会话为**进程内内存**存储（`context_manager`），接口已预留 Redis 替换空间；重启即清空。
- 登录令牌同样**内存存储**（TTL 24h），重启需重新登录。

### 2.6 「数据归后端」决策（2026-09-18，用户要求）

前端不存数据文件，数据全部放后端、由后端按**前端原有相对路径**提供（前端代码一行未改）：

| 前端请求的路径（未变） | 后端实际来源 | 实现 |
|---|---|---|
| `/assets/videos/*.mp4`、`*-cover.jpg` | `data/media/videos/` | `backend/controller/media.py` |
| `/assets/papers/*.pdf` | `data/media/papers/` | 同上 |
| `/assets/books/*.png` | `data/media/books/` | 同上 |
| `/data/videos.json` | `data/media/videos.json` | 同上 |
| `/api/kline?secid=…` | 新浪（A股/港美股）；北证50 东财优先、新浪兜底 | 同上 |
| `/api/news` | 新浪滚动新闻，5 分钟内存缓存 | 同上 |
| 其余（`/`、`/index.html`、`/js/*`、`/css/*`、`/assets/fonts/*`…） | `前端/SUFE-Knowledge-Galaxy/` | `mount_site()` |

- 视频/PDF 走 Starlette `StaticFiles` → **支持 HTTP Range**（206），进度条可拖。
- ✅ 以后再加数据（视频/论文/封面/清单）→ 放 `data/media/` 并由后端出路径，**不要写进前端目录**。
- ✅ 仍留在前端的东西：页面自身素材（css/js/字体/校徽）与硬编码页面配置（`js/main.js` 里的 `BOOKS` 35 本、`JOURNALS` 论文元数据），属"页面配置"不是"数据文件"，迁移需前端配合，**暂未动**。

### 2.7 认证与个人状态接口（后端已实现）

- 密码 PBKDF2-HMAC-SHA256 + 随机盐；重名 409 `{code,message}`；`HTTPException` 统一返回 `{code, message, detail}`。
- ⚠️ `/api/graph/*` **故意不校验登录**（前端登录页是后来才加的）；将来要加就用 `auth.py` 的 `current_user` 依赖。
