# Agent 期望控制层传入的 `GraphData` 格式说明

**用途**：控制层调用 Agent 的 `answer` 方法时，需按以下格式传入 `graph_data` 参数。  
**原则**：必填字段必须提供；可选字段可省略或为 `null`；字段命名需与本文档一致。

---

## 一、整体结构

```json
{
  "graph_id": "corporate_finance",
  "title": "公司金融 进阶篇 原书第12版",
  "nodes": [ ... ],
  "edges": [ ... ]
}
```

| 字段 | 类型 | 必填 | 说明 |
| :--- | :--- | :--- | :--- |
| `graph_id` | string | **是** | 图谱标识，用于 Agent 缓存隔离和多书区分 |
| `title` | string | 否 | 书名，仅用于日志或展示 |
| `nodes` | array | **是** | 节点列表，至少一个节点 |
| `edges` | array | **是** | 边列表，可为空数组 |

---

## 二、节点（`nodes` 数组元素）

```json
{
  "id": "concept_2499",
  "label": "资本结构",
  "type": "concept",
  "page": 365,
  "media": null,
  "extra": {}
}
```

| 字段 | 类型 | 必填 | 说明 |
| :--- | :--- | :--- | :--- |
| `id` | string | **是** | 节点唯一 ID，用于生成超链接的 `data-node-id` |
| `label` | string | **是** | 节点显示名，用于检索和答案上标显示 |
| `type` | string | 否 | 节点类型，如 `concept` / `formula` / `chapter` / `section` |
| `page` | int | 否 | 页码，可为 `null` |
| `media` | object | 否 | 预留字段，当前无数据。格式：`{"image_url": "...", "video_url": "..."}` |
| `extra` | object | 否 | 各书特有字段，Agent 不解析，透传给前端 |

**注意**：控制层现有 `GraphNode` 字段为 `name` 和 `category`，需统一改为 `label` 和 `type`。

---

## 三、边（`edges` 数组元素）

```json
{
  "source": "chapter_2227",
  "target": "concept_2499",
  "relation": "包含概念",
  "extra": {}
}
```

| 字段 | 类型 | 必填 | 说明 |
| :--- | :--- | :--- | :--- |
| `source` | string | **是** | 起点节点 ID |
| `target` | string | **是** | 终点节点 ID |
| `relation` | string | **是** | 关系类型，如“包含概念”“相关” |
| `extra` | object | 否 | 兜底字段，当前无数据 |

---

## 四、完整示例

```json
{
  "graph_id": "corporate_finance",
  "title": "公司金融 进阶篇 原书第12版",
  "nodes": [
    {
      "id": "concept_2499",
      "label": "资本结构",
      "type": "concept",
      "page": 365,
      "media": null,
      "extra": {}
    },
    {
      "id": "chapter_2227",
      "label": "第33章 世界范围的公司治理和控制",
      "type": "chapter",
      "page": 328,
      "media": null,
      "extra": {}
    }
  ],
  "edges": [
    {
      "source": "chapter_2227",
      "target": "concept_2499",
      "relation": "包含概念",
      "extra": {}
    }
  ]
}
```

---

## 五、必填字段速查

| 层级 | 必填字段 |
| :--- | :--- |
| 图级 | `graph_id`、`nodes`、`edges` |
| 节点 | `id`、`label` |
| 边 | `source`、`target`、`relation` |

**只要以上 8 个字段齐全，Agent 即可正常完成检索和答案生成。**  
可选字段缺失时，Agent 内部会判空处理，不影响核心功能。
